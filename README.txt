Заполните адрес, порт, логин и пароль. Выберите приложения, примените и подключитесь.
Enter server, port, username and password. Select apps, apply and connect.
Server, Port, Benutzername und Passwort eingeben. Apps wählen, anwenden und verbinden.
Introduce servidor, puerto, usuario y contraseña. Elige apps, aplica y conecta.

При подключении выбранные приложения используют прокси, остальные — провайдера.
While connected, selected apps use the proxy; other apps use the ISP.
Bei Verbindung nutzen gewählte Apps den Proxy, andere den Internetanbieter.
Al conectar, las apps elegidas usan el proxy y las demás el proveedor.

ProxyChoiceApp uses its proxy for its own internet access while connected.
Microsoft Store is selected by default and can be disabled.
Installed YouTube is selected on first start when found; a web app shares its browser's routing.
Private LAN addresses, including 192.168.8.1, remain direct.
Administrator permission is required only when enabling the TUN tunnel.
Exit and Disconnect restore ordinary ISP routing. There is no persistent kill switch.
The Help tab is available in English, French, Spanish, Chinese, German and Russian.
The runtime and engine are included. No separate .NET installation is required.
Settings: %LOCALAPPDATA%\ProxyChoiceApp (passwords protected by Windows DPAPI).
The source package includes application source and exact bundled engine source.
