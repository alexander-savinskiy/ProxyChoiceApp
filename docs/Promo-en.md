# ProxyChoicePro — app proxies and your work network

Choose applications for SOCKS5, HTTP or HTTPS, or connect to a work network through WireGuard and use normal Windows Remote Desktop.

Saved profiles and work PCs, separate network/RDP diagnostics, subnet overlap detection and automatic connection recovery. Adaptive tabs, night mode and a consistent whole-icon status color. Interface, installer and documentation in six languages.

Windows 10/11 x64. Standalone EXE and installer include required components. Work access requires a WireGuard client profile registered on the work router.
