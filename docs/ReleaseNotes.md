# ProxyChoiceApp 1.0.0

**Alexander Savinskiy · A.savinskiy@gmai.com**

**Русский:** Windows-приложение для выбора программ, которые идут через прокси. ProxyChoiceApp всегда через прокси при подключении; Microsoft Store включён по умолчанию. Chrome, Edge и установленный YouTube, несколько профилей, скорость и мегабайты, очистка журнала, шесть языков и подробная справка.

**English:** Choose the applications that use your proxy. ProxyChoiceApp always follows the proxy while connected; Microsoft Store is enabled by default. Chrome, Edge and installed YouTube, multiple profiles, speed/traffic counters, clearable journal, six languages and detailed help.

**Deutsch:** Gewählte Apps nutzen den Proxy. ProxyChoiceApp selbst bleibt bei aktiver Verbindung auf dem Proxy; Microsoft Store ist standardmäßig aktiviert. Chrome, Edge und installiertes YouTube, mehrere Profile, Geschwindigkeit und Datenmengen, löschbares Protokoll, sechs Sprachen und ausführliche Hilfe.

**Español:** Elige las apps que usan el proxy. ProxyChoiceApp usa siempre el proxy mientras está conectado; Microsoft Store está activado por defecto. Chrome, Edge y YouTube instalado, varios perfiles, velocidad y tráfico, registro limpiable, seis idiomas y ayuda detallada.

Use **ProxyChoiceApp-Setup.exe** to install, or **ProxyChoiceApp.exe** to run standalone. No separate .NET installation is needed. Windows 10/11 x64. App choices require Apply and restarting affected apps. Private LAN traffic remains direct. This app restores ISP routing on exit or core failure. See the guides for DNS, Store endpoint and UDP behavior.

Verify downloads against **SHA256SUMS.txt**. **source.zip** includes the application, pinned engine and corresponding upstream source. GPL-3.0-or-later; component notices accompany every package.
