# ProxyChoicePro — прокси приложений и доступ к рабочей сети

Выбирайте приложения для SOCKS5, HTTP или HTTPS либо подключайтесь к рабочей сети через WireGuard и открывайте обычный удалённый рабочий стол Windows.

Сохранённые профили и рабочие ПК, отдельные проверки сети и RDP, обнаружение совпадающих подсетей, автоматическое восстановление соединения. Адаптивные вкладки, ночной режим и единый цвет всего значка показывают состояние подключения. Интерфейс, установщик и документация доступны на шести языках.

Windows 10/11 x64. Готовые EXE и установщик содержат необходимые компоненты. Для рабочей сети нужен клиентский профиль WireGuard, зарегистрированный на рабочем роутере.
