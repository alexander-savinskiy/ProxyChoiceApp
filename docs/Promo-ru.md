# ProxyChoiceApp — прокси для тех приложений, которые вы выбираете

Нужен прокси для браузера или Microsoft Store, а остальные программы должны работать через обычное подключение? **ProxyChoiceApp** помогает выбрать нужный маршрут в одном понятном окне.

Введите адрес, порт, логин и пароль, отметьте приложения и подключитесь. Chrome и Edge можно выбирать отдельно. Microsoft Store включён по умолчанию, а установленное приложение YouTube добавляется при обнаружении. Если YouTube работает внутри браузера, он использует маршрут этого браузера.

**Всё для удобной работы:**

- Несколько сохранённых прокси и поддержка SOCKS5, HTTP и HTTPS.
- Проверка IP прокси, текущая скорость, объём принятых и отправленных данных.
- Кнопка отключения и красный или зелёный значок состояния.
- Компактное окно, читаемые шрифты и подробная встроенная справка.
- Шесть языков интерфейса с флажками, очистка и экспорт журнала.
- Зашифрованное хранение сохранённых параметров и паролей в Windows.

Запускайте отдельный **EXE** или используйте готовый установщик для Windows 10/11 x64. Все необходимые компоненты уже включены.

**Выбирайте приложения. Управляйте подключением. Работайте удобнее с ProxyChoiceApp.**
